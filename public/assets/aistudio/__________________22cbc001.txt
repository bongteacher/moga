# 구현할 기능
교직원들이 자유롭게 게시판에 의견을 남길 수 있음\
게시글을 보고 좋아요 투표 기능
관리자 대시보드

#각 메뉴별 구현 기능

1. 게시판 (인사말 & 아이디어 남기기)
인트로: 교직원 환영 문구 및 사이트 안내문구
아이디어 작성 폼:
닉네임 입력 (선택, 비워두면 "익명의 작성자"로 표시)
카테고리 선택 (드롭다운): AI활용 / 수업자료제작 / 이미지생성 / 영상제작 / 업무자동화 / 글쓰기 / 기타
제목 입력 (한 줄, 필수): 아이디어를 한 줄로 요약
부연 설명 입력 (텍스트 영역, 선택, 최대 300자): 좀 더 구체적인 설명이나 배경 
placeholder: "더 자세히 알려주시면 영상 제작에 큰 도움이 됩니다! (선택)"
"아이디어 남기기" 버튼

좋아요(Voting): 각 제안글에 '공감' 버튼 배치
실시간 랭킹: 좋아요를 많이 받은 '인기 주제'들이 패널에 노출.

2. 모아보기(전체 아이디어 보기 & 검색)
데이터 리스트: 모든 제안을 최신순/좋아요순으로 정렬,
페이지네이션: 글이 많아질 경우 하단에 [1, 2, 3...] 번호로 구분.
다면 필터링: 카테고리별 선택 및 키워드 검색 기능 제공.

3.구현
실제 바이브 코딩으로 제작된 경우, 제목, 링크를 카드 형태로 노출 운영자만 추가할 수 있음

#관리자 기능
구글계정 로그인(특정 이메일만 운영자 권한 부여)
운영자 전용 기능
의견 삭제
의견 반영 바이브코딩 웹앱 페이시에 추가, 수정, 삭제
의견 목록 csv 다운로드(날짜, 카테고리, 내용, 좋아요 수)
운영자 고르인 버튼은 페이지 하단 푸터에 작게 배치
