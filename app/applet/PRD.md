# 제품 요구사항 정의서 (PRD: Product Requirements Document)

## 프로젝트명
**교직원 마이크로 바이브 미니홈피 (교직원 아이디어 & 바이브 코딩 공감 게시판)**

---

## 1. 프로젝트 배경 및 목적

### 1.1 배경
- 학교 현장에서 교직원들이 겪는 업무 비효율, 수업 자료 제작의 애로사항, AI/영상/이미지 도구 활용에 대한 다양한 요구가 존재합니다.
- 복잡하고 무거운 사내 그룹웨어 대신, 누구나 쉽고 재미있게 참여할 수 있는 소통 채널이 필요합니다.
- 특히 인공지능 기반 바이브 코딩(Vibe Coding)을 통해 교직원의 아이디어가 실제 작동하는 소프트웨어/웹앱으로 빠르게 현실화되는 과정을 공유하고 피드백을 나눌 수 있는 전용 플랫폼이 요구됩니다.

### 1.2 목적
1. **자유로운 아이디어 수렴**: 로그인 부담 없이 익명 또는 원하는 닉네임으로 AI 활용, 업무 자동화, 수업 자료 관련 제안 접수
2. **공감 기반 우선순위 발굴**: 교직원들의 '공감(좋아요)' 투표를 통한 실시간 인기 제안 선정 및 랭킹 시각화
3. **바이브 코딩 구현작 투명 공유**: 제안된 아이디어가 실제 웹앱으로 제작된 사례를 카드 형태로 전시하여 업무 적용 촉진
4. **간편한 운영자 관리 체계**: 구글 계정 기반 인가, 악성 제안 삭제, 구현 웹앱 등록, 설문 통계 분석용 CSV 내보내기 지원
5. **친근하고 즐거운 참여 경험**: 2000년대 싸이월드 미니홈피 감성의 레트로 UI(도트 테두리, 우측 탭 내비게이션, 오렌지/스카이블루 파스텔 톤)로 참여 재미 극대화

## 3. 핵심 메뉴 및 상세 기능 명세

### 3.1 레이아웃 구조: 2000년대 싸이월드 미니홈피 감성

- **헤더 영역**:
  - `● 교직원 사랑방 ●` 타이틀 및 상태 메시지
  - `Today 34 | Total 1,280` 실시간 방문자 카운터
  - 레트로 BGM 상태바 (`♫ 프리스타일 - Y (교원 스마트 업무 에디션) [재생중]`)
- **좌측 사이드바 (프로필 룸)**:
  - 교직원 마스코트 도트 프로필 이미지
  - 교직원 소통 환영 인사말 및 "아이디어가 실제로 개발됩니다" 안내
  - 오늘의 기분 / 소통 한마디 문구
- **우측 네비게이션 탭 (Retro Tabs)**:
  - `[홈 / 아이디어]` (Home & Submit)
  - `[모아보기]` (Idea Archive)
  - `[구현 갤러리]` (Vibe Apps)
  - `[운영자 센터]` (Admin Room - 권한 계정 활성화)

### 3.2 메뉴별 기능 명세

#### [메뉴 1] 홈 & 아이디어 (인사말 & 아이디어 남기기)
1. **인트로 영역**:
   - 친절하고 따뜻한 교직원 환영 메시지
   - "여러분의 작은 아이디어가 AI 바이브 코딩을 통해 실제 업무/수업 앱으로 제작됩니다!" 가이드
2. **아이디어 작성 폼**:
   - **닉네임**: 텍스트 입력 (선택, 미입력 시 `"익명의 작성자"` 기본값)
   - **카테고리 선택** (드롭다운, 필수):
     - `AI활용`
     - `수업자료제작`
     - `이미지생성`
     - `영상제작`
     - `업무자동화`
     - `글쓰기`
     - `기타`
   - **제목**: 1줄 텍스트 입력 (필수, 최대 60자, "아이디어를 한 줄로 요약해 주세요")
   - **부연 설명**: 다중 행 텍스트 영역 (선택, 최대 300자 실시간 카운터 제공)
     - Placeholder: `"더 자세히 알려주시면 영상/웹앱 제작에 큰 도움이 됩니다! (선택)"`
   - **제출 버튼**: `"아이디어 남기기"` (클릭 시 즉시 서버 저장 및 목록 갱신)
3. **공감(Voting) 및 실시간 랭킹 패널**:
   - 제안글마다 직관적인 '공감(하트/좋아요)' 버튼 및 카운트
   - 공감 수 상위 3~5개 제안을 '실시간 인기 랭킹' 전광판에 하이라이트 노출
   - 최근 등록된 최신 아이디어 피드 즉시 확인 가능

#### [메뉴 2] 모아보기 (전체 아이디어 보기 & 검색)
1. **데이터 리스트 뷰**:
   - 등록된 모든 제안 글의 일목요연한 카드/테이블 뷰
   - 작성일자, 카테고리, 닉네임, 제목, 상세설명(접기/펼치기), 공감 수 표시
2. **다면 필터링 & 키워드 검색**:
   - 카테고리별 원클릭 필터 버튼 (전체 / AI활용 / 수업자료제작 / 이미지생성 / 영상제작 / 업무자동화 / 글쓰기 / 기타)
   - 실시간 키워드 검색바 (제목 및 내용 일치 검색)
3. **정렬 토글**:
   - `최신순` (최근 등록일 기준)
   - `공감순` (좋아요를 많이 받은 순)
4. **페이지네이션**:
   - 페이지당 6~10개 단위 분할 표시
   - 하단 `[1, 2, 3, …]` 페이지 번호 내비게이션

#### [메뉴 3] 구현 (Vibe Coding Showcase)
1. **쇼케이스 카드 목록**:
   - 교직원 아이디어를 바탕으로 실제 바이브 코딩으로 제작된 웹앱 리스트 노출
   - 카드 구성: 썸네일/아이콘, 앱 제목, 해결한 교직원 제안 내용 요약, 사용된 AI 기술, "체험하러 가기(새 창)" 링크 버튼
2. **운영자 전용 관리**:
   - 운영자로 로그인된 상태에서만 `[+ 새 구현작 등록]` 버튼 표시
   - 등록/수정/삭제 모달을 통해 제목, 상세설명, 카테고리, URL, 썸네일 태그 직접 관리

#### [메뉴 4] 관리자 기능 (Admin Console)
1. **운영자 로그인**:
   - 페이지 최하단 푸터에 조용하고 작게 `[운영자 로그인]` 버튼 배치
   - Google 계정 연동 인증 (기본 관리자 이메일: `t2501@icheonhs.goeic.kr`)
   - 권한이 확인되면 상단 네비게이션에 `[운영자 관리]` 탭 또는 관리자 모드 배지 표시
2. **의견 관리 (삭제 기능)**:
   - 각 게시글 카드에 운영자 전용 `[삭제]` 버튼 활성화 (삭제 전 확인 다이얼로그)
3. **구현 웹앱 CRUD**:
   - 구현 페이지의 카드 추가, 내용 수정, 삭제 권한
4. **의견 목록 CSV 다운로드**:
   - `[의견 목록 CSV 다운로드]` 버튼 제공
   - 포함 컬럼: `등록일시`, `카테고리`, `닉네임`, `제목`, `상세내용`, `공감수`
   - 한글 깨짐 방지를 위한 UTF-8 BOM 인코딩 적용

## 4. 데이터 모델 및 API 설계

### 4.1 데이터 구조
```typescript
interface IdeaItem {
  id: string;              // 고유 UUID
  nickname: string;        // 닉네임 (기본: "익명의 작성자")
  category: 'AI활용' | '수업자료제작' | '이미지생성' | '영상제작' | '업무자동화' | '글쓰기' | '기타';
  title: string;           // 1줄 요약 제목 (필수)
  description?: string;    // 상세 배경/설명 (최대 300자)
  likes: number;           // 공감 수
  createdAt: string;       // ISO 등록 일시
}

interface VibeAppItem {
  id: string;              // 고유 UUID
  title: string;           // 웹앱 명칭
  description: string;     // 앱 소개 및 해결한 업무 문제
  category: string;        // 관련 카테고리
  url: string;             // 바로가기 외부/내부 URL
  tag: string;             // 예: "완료", "운영중", "Vibe Coding"
  createdAt: string;       // 등록일
}
```

### 4.2 API 엔드포인트 (Express 서버)
- `GET /api/ideas`: 전체 제안 목록 조회 (정렬, 카테고리, 검색어, 페이지 지원)
- `POST /api/ideas`: 신규 아이디어 등록
- `POST /api/ideas/:id/like`: 해당 아이디어 공감 투표 (+1)
- `DELETE /api/ideas/:id`: 아이디어 삭제 (운영자 전용)
- `GET /api/vibe-apps`: 바이브 코딩 구현작 목록 조회
- `POST /api/vibe-apps`: 구현작 신규 등록 (운영자 전용)
- `PUT /api/vibe-apps/:id`: 구현작 정보 수정 (운영자 전용)
- `DELETE /api/vibe-apps/:id`: 구현작 삭제 (운영자 전용)
- `GET /api/admin/export-csv`: 전체 제안 데이터 CSV 스트림 다운로드
- `POST /api/admin/auth`: 운영자 계정 검증 및 권한 확인

## 5. UI/UX 디자인 가이드라인 (싸이월드 레트로 감성)
- **주요 색상**:
  - 배경: 은은한 파스텔 회색/베이지 도트 패턴 (`#F0F2F5`)
  - 미니홈피 프레임: 클래식 스카이블루/오렌지 포인트 (`#2B72B9`, `#FF6E30`)
  - 내부 컨테이너: 순백색 및 소프트 실버 보더 (`#FFFFFF`, `#D5DCE4`)
  - 텍스트: 선명하고 가독성 높은 차콜 블랙 (`#2D3748`, `#4A5568`)
- **컴포넌트 스타일**:
  - 도트 실선 테두리 (`border: 1px dashed / dotted`)
  - 미니홈피 특유의 우측 세로 돌출 탭 (선택된 탭은 흰색으로 본문과 이어지는 클래식 룩)
  - 깜찍한 픽셀 감성의 아이콘 및 말풍선
- **반응형 대응**:
  - 데스크톱(1024px 이상)에서는 완벽한 2단 미니홈피(좌측 프로필 + 우측 메인룸 + 우측 탭) 레이아웃
  - 모바일/태블릿에서는 탭이 상단/하단으로 자연스럽게 스택되는 유연한 레이아웃

## 6. 성공 기준 및 검증 계획
1. **아이디어 등록 및 실시간 공유**: 교직원 A가 등록한 글이 즉시 서버에 저장되고 다른 접속자에게도 노출되는지 확인
2. **공감 투표 및 랭킹 갱신**: 공감 버튼 클릭 시 좋아요 수가 즉시 증가하고 실시간 랭킹에 반영되는지 확인
3. **검색 및 필터링 동작**: 카테고리 탭 선택 및 검색어 입력 시 정확한 리스트가 필터링되는지 확인
4. **구현 갤러리 연동**: 실제 제작된 바이브 코딩 웹앱 카드가 깔끔하게 노출되고 클릭 시 새 탭으로 올바르게 연결되는지 확인
5. **관리자 기능 및 CSV 다운로드**: 지정된 구글 계정으로 로그인 후 글 삭제 및 엑셀에서 한글이 깨지지 않는 CSV 다운로드 동작 검증
